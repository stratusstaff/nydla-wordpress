# NYDLA WordPress theme — status

**Theme name:** NYDLA WordPress  
**What NYDLA means:** New York Distance Learning Association

## Links

- **See it live:** https://merciful-darkturquoise-giraffe-37.hostingersite.com/
- **Code / download:** https://github.com/stratusstaff/nydla-wordpress

## What’s done (v1)

This is a custom WordPress theme (not Elementor, not a page builder).

You can install it, activate it, and build pages with it. The design system and page “building blocks” are in place. Real NYDLA content has **not** been moved over yet.

**Included:**

- Theme files ready to upload (`nydla-wordpress` folder)
- Site header (logo + menu) and footer
- Mobile menu
- Colors, fonts, and spacing set up
- Skyline images for empty picture slots
- Ready-made page layouts (patterns) for:
  - Home hero
  - About / mission
  - Sponsors
  - Podcasts
  - Events
  - Contact / Join
  - Sponsor mini-site (for later NYDLA.biz pages)

## What’s next

- Build the actual pages using those patterns
- Add real text, logos, and forms
- No content migration from the old site yet

## How to get the files

1. Open the GitHub link above  
2. Click **Code → Download ZIP**  
3. In WordPress: **Appearance → Themes → Add New → Upload Theme**  
4. Upload the zip and activate **NYDLA WordPress**
