# NYDLA WordPress theme — status

**Theme name:** NYDLA WordPress  
**What NYDLA means:** New York Distance Learning Association

## Links

- **See it live:** https://merciful-darkturquoise-giraffe-37.hostingersite.com/
- **Code / download:** https://github.com/stratusstaff/nydla-wordpress

## What’s done (v1)

Custom WordPress theme (no Elementor / page builder). Design system + page building blocks are ready. Full content migration is **not** done yet.

**Included:**

- Theme ready to upload and activate
- Header (logo + menu), footer, mobile menu
- Colors, fonts, spacing
- Skyline placeholders for empty images
- Patterns you can drop into pages:
  - Home hero
  - About / mission
  - **Journey arc** — Distance Learning → DIGITAL Learning → DIGITAL LIVING
  - **Three pillars** — Knowledge + Technology + Talent
  - Sponsors / Podcasts / Events
  - Contact / Join
  - Sponsor mini-site (later NYDLA.biz)

2. **Code → Download ZIP**  
3. WordPress: **Appearance → Themes → Upload Theme**  
4. Activate **NYDLA WordPress**
