# Header redesign (v1.2.0)

Upload this theme version to staging to see the new header.

## What changed

- Real **NYDLA.org logo** ships in the theme (`assets/images/brand/nydla-logo.png`)
- **New layout:** logo centered on top, nav bar underneath (not the old left-logo / right-menu boilerplate)
- Navy nav strip, uppercase links, amber/green accents
- Mobile: logo on top, hamburger in the navy bar

## How to upload

1. Zip the `nydla-wordpress` folder  
2. WordPress → Appearance → Themes → Add New → Upload  
3. Or replace the theme folder over Hostinger file manager  

Customizer logo still overrides the bundled logo if you set one later.
